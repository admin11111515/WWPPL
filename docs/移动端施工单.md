| 项 | 数量（平板 768×1024） |
|---|---|
| < 24px | 0 ✅ |
| < 44px | 810 处 |
| 文字 < 12px | 524 处 |

**后台的两个根因（都不是"哪一页写坏了"）**：

1. **窄屏根字号跟着前台缩到 14px**。后台 `<html>` 用的是前台的
   `text-[14px] md:text-[16px]`，而 `admin.css` 全用 rem → 窄屏上**所有尺寸缩 12.5%**：
   13px 的入口文字变 11.375px、**11px 的说明文字变 9.625px**。这不是某页的问题，是整套的。
2. **14 个入口挤成一条横向滚动带，且从中间切断**。`@media (max-width:900px)` 把侧栏改成横条是对的，
   但没有"还能滑"的提示，且滚动容器会**把第 6 项「技能」切成「技」**（截图 `_gen/_out/amob-390-首页-*.png`）；
   分组标签在窄屏被 `display:none` 掉，于是 14 项平铺、结构也丢了。

## 三、今晚改哪些

### P0 —— 手机上已经"坏了"的
- **A1 顶部横条**：不再从中间切断 · 两端渐隐提示还能滑 · 当前页所在项载入时自动滚到可见
  · 分组之间补分隔线 · 项高抬到 44px（手机上的主要导航）。
  ⚠️ **不要写 `scroll-snap`**：脚本要给"当前项居中"设 `scrollLeft`，而 scroll-snap 会在滚动
  结束后把位置吸附回最近的吸附点 —— 两者互相打架（载入时引擎还可能先吸一次，早于脚本）。
  这条横向带不需要吸附，位置由脚本算更可控。
  判据：当前项**完整可见** + 有内容可滑时渐隐类挂上（`can-left`/`can-right`）。
- **A2 窗格切换按钮 37×23** → 手机 ≥44px（这是文章/笔记页在手机上最主要的交互）。
- **A3 前台 4 处 <24px 触控目标** → 独立可点元素给 ≥44px 命中区（面包屑这类行内的 ≥32px）。

### P1 —— 展示
- **B1 后台窄屏根字号保持 16px**（后台是工具界面，不跟博客的 14px 缩）。
- **B2 后台手机触控目标**：可点元素 ≥44px（含只带图标的那些的宽度）。
  ⚠️ 动之前先看**量具口径**：正文行内链接不该算（否则数字永远归不了零）。
- **B3 前台过小文字**：
  ⚠️ **门槛要按主题自己的手机刻度定**：前台手机根字号 14px，`text-xs`(0.75rem) 会变成 **10.5px**，
  那是主题**有意的**手机刻度，不该当问题。真正要修的是**低于这条线的异类**：
  友链申请表单标签（0.65rem → 手机 9.1px）与说说元信息（0.6875rem → 手机 9.6px）。
  改法只在手机上抬到 11px（`max(11px, …)` / `text-[11px] md:text-[0.65rem]`），桌面不动。

### P2 —— 记下，今晚不动（需要站长拍板或另有准绳）
- 音乐艺人名的省略号（设计如此；要改就是两行或走马灯）。
- 图片 width/height（以 CLS 量具为准）。
- 超长表单页（技能页保存按钮在手机第 15.7 屏）—— 已有悬浮保存条 + `Ctrl/⌘+S` 兜着；
  要进一步就是"页内回顶/回底"辅助，属新功能，先不做。
