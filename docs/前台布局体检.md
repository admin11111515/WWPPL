## 一、判据（全部能量出来，不涉及审美）

| # | 指标 | 判据 | 阈值 |
|---|---|---|---|
| 1 | 横向溢出 | `scrollWidth − innerWidth` | ≤ 1px |
| 2 | 元素越界 | 可见元素左右超出视口，**且没被任何祖先的 overflow 裁掉** | 不许有 |
| 3 | 行长 | 正文列宽 ÷ 字号 = 一行多少汉字 | 30~45 字 |
| 4 | 行高 | 正文字号 ÷ 行高 | 1.5~2.1 |
| 5 | 字号过小 | 可见文字 < 12px | 不许有 |
| 6 | 触控目标 | 可点元素 < 24px（段落内行内链接除外） | 不许有 |
| 7 | 文字被单行硬切 | `text-overflow: ellipsis` 且 `scrollWidth > clientWidth` | 内容区不许有 |
| 8 | 图片缺尺寸 | 无 `width/height` 且父级无固定比例 | 会跳版，需实证 |
| 9 | 正文占屏比 | 正文列宽 ÷ 视口 | 宽屏 ≥ 42% |
| 10 | 固定定位覆盖 | `position: fixed` 盖住多少视口 | 只作提示 |

## 二、两个必须知道的坑（都踩过）

1. **跨层不是"比特异性"，是"按层序"。**
   `src/styles/main.css` 里绝大多数规则包在 `@layer components` 里，而 Tailwind 工具类在
   `@layer utilities`（排在**后面**）→ 同一个元素上工具类**永远赢**，哪怕你写了
   `#navbar-actions .btn-plain`（特异性 1,1,1）。要盖过工具类的规则**一律放文件末尾的无分层区**。
   （后台的 `admin.css` 整个文件都是无层的，同一个道理，但方向相反 —— 那份要压 Tailwind。）

2. **假阳性比漏报更贵**，第一版 92/92 全中，噪声占一半：
   - `clipped()` 的循环条件写成 `p !== document.body` → **`body` 上的 `overflow-x: hidden`
     没被算进去**，`#header-waves` 那套装饰 SVG 被误报成"越界"（23 个页面全中）。
     条件要写成 `while (p)`，走到 body/html 为止。
   - SVG 内部图元（`g`/`use`/`path`）常用很大的负坐标画形状，必须单独跳过。
   - 侧栏、显示设置面板、轮播轨道**本来就故意放在视口外**，靠 overflow 收住。
   - 「触控目标」「字号」只统计**中心点在视口内**的元素。
   - 轮播/横幅在动画中途量会拿到缩放后的字号（同一处先后量到 7px / 8.1px / 量不到）。
     判据要**测两次取交集**，只报两次都出现的。
   - 判「数据到了以后换掉了」不能断言"一定有内容"：空列表页给的是**明确的空态**，
     判据应是「内容 > 0 **或** 空态 > 0」。

**第 2 条有个陷阱**：真正渲染前台的是 `DisplaySettingsIntegrated.svelte`（Navbar 引的是它），
另一个 `DisplaySettings.svelte` 里也有一模一样的规则 —— 改错文件会"改了没反应"。

**第 6 条别顺手扩大**：`text-sm` / `text-base` 也用 px 覆盖等于换全站正文字号，
那是设计决定（"根字号 14px"是刻意选的密度）。

## 四、第二批（提交 `3591c88`）

横幅副标题与「全部文章」按钮重叠：`.banner-subtitle` 用 `max-width: max-content`，

  整列，1056px），要限宽就得改卡片版面 —— 文字变窄后右侧会留白。
  文章/关于页已通过 `.custom-md` 解决（42 字），这两个是同类问题的另一半。
- ~~**图片缺尺寸（跳版）** 体检仍会报，但没有实测位移证据~~ → **2026-10-08 实测完，是误报**。
  尺子 `_gen/_图片CLS实测.mjs`，用的是 `layout-shift` 性能观测器（权威口径），
  并且**必须**加"禁缓存 + 慢网"那一趟：本地预览图是瞬时就到，就算页面没给图预留位置，
  位移也会发生在首帧之前、CLS 量不到 —— 不加那一趟就是被测环境骗了。

  实测（CLS<0.1 为「好」）：

  | 页面 | 正常 | 禁缓存 + 慢网 ← 定论 |
  |---|---|---|
  | 首页 | 0.0127 | **0.027** |
  | 文章列表 | 0.0001 | **0** |
  | 文章详情 | 0.0001 | **0** |
  | 说说 | 0.0001 | **0** |

  → 封面外面那层定尺容器是有效的，**不用给图片补尺寸**。

  ⚠️ 脚本里还留了一条"拦图 vs 放图比位置"的对比，**它不能当判据**：
  图被拦掉时没设高度的那张自己会塌，底下所有东西整体上移 —— 那说明的是
  "这张图没预留位置"，不说明"图加载出来时会不会顶下去"（后者看上面那两趟）。
  它只当**定位诊断**用。当前它指到的是音乐播放器封面（网易云 CDN），
  那张在 `w-16 h-16` 定尺容器里，也不跳版。
