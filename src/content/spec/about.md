# 关于我

你好，我是 WWPPL，广东汕头人。

专科读的软件技术，本科转去读机械设计制造及其自动化，现在对人工智能应用这块很感兴趣。白天和代码打交道，晚上喜欢听歌、看番、拍照，偶尔写点东西。

这个博客从模板到细节基本都是我自己改出来的，从第一篇文章到现在的日记、说说、相册，慢慢长成了我想要的样子。

## 生活与诗篇

- **读书** — 偏爱散文和诗歌，也看小说。遇到好的句子会抄下来，偶尔翻回去看
- **听歌** — 网易云重度用户，歌单什么都有。有时候一首歌能单曲循环一下午
- **追番** — 新番老番都看，治愈系来者不拒。周末窝在家里看一整天也不觉得浪费
- **拍照** — 手机为主，拍路边的猫、傍晚的云，也拍楼下难吃但每天都排队的肠粉店
- **写字** — 日记、说说、随笔，想到什么写什么。不一定深刻，但都是真实的

生活大部分时间是普通的：上课、写代码、吃饭、睡觉。但我总想留住一点什么，比如修 bug 到凌晨两点时窗外刚好下雨，比如跑步跑不动就坐下来看夕阳。这些瞬间很小，记下来之后，回头翻的时候还能想起当时的心情。

## 关于代码

专科读软件技术，算是我和代码正式打交道的起点；本科转去学机械设计制造及其自动化，绕了一圈，发现还是喜欢用技术做点东西。现在对人工智能应用很感兴趣，平时做前端多一些：Astro / Vue / Svelte / TypeScript，偶尔用 Node.js 写点小工具，或者用 Python 解决琐碎问题。

写代码对我来说更像整理房间：不一定多高级，但喜欢干净、顺手、能看懂。比起追新技术，更在意能不能优雅地解决问题。

代码只是我生活的一部分，它让我多了一种创造和表达的方式，但生活里值得关注的东西还有很多。
