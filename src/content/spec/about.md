# 关于我

我是 WWPPL，汕头人，本职是程序员，写前端。

学历这条线有点绕：专科读的软件技术，专升本转去机械设计制造及其自动化。所以现在的状态是白天上班写代码，晚上有时候还得上课——两边都没落下，两边的活儿都嫌多。

工作上主要写 Astro、Vue、Svelte、TypeScript。偶尔用 Node.js 写点小工具，或者拿 Python 处理表格。都是不高级的活，但我喜欢它们干净、顺手、半年后自己还能看懂。

业余时间大半花在最新出的那些人工智能小玩意上。不是追风口，纯粹好奇——把大模型塞进一件具体的事里，到底能塞到什么程度。水平是业余的，做出来的东西也大多没给别人用。

## 平时在干什么

读书偏散文和诗歌，小说也看，但看得慢。看到好句子会抄下来，抄在同一个本子上，抄完很少翻回去。

听歌是网易云重度用户，歌单很杂。写代码的时候不敢放有词的——中文歌我一定会跟着听，思路就断了。

追番新老都看，治愈系来者不拒。周末窝着看一整天，看完会有种"这天好歹也算过了"的踏实。

拍照用手机。拍楼下的猫、傍晚的云，也拍金砂路那家每天都排队的肠粉店——味道其实一般，但三块五一份，我大概去了五十次。

## 这个小站

三个地方：生活放日记、说说、相册；文字放随笔和读到的东西；技术放踩坑记录。

模板不是我自己写的（Firefly），但这两年被我改得亲妈都认不出来。改的过程中踩的坑基本都进了技术分类——主要是写给我自己看的，因为我知道下次一定还会踩。

更新不快。想写才写，凑数写出来的东西我自己都不想看。
