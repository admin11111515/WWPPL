暗色主题看着简单——把背景改黑、字改白不就行了。实际做起来发现有一堆细节，都是同一个原因：颜色不是孤立的。

## 只换颜色不够

浅色模式下常用的纯黑文字配纯白背景，对比度大概是 21:1，很舒服。反过来，暗色模式下如果用纯白文字配纯黑背景，对比度同样是 21:1，但看起来会"发光"，字边有光晕，看久了眼睛累。

原因是纯黑和纯白都是极端值，明暗切换时人眼适应不了。所以暗色模式里，背景一般用接近黑但不是黑的深灰（比如 #0f1115），文字也不用纯白，用接近白但带一点灰的（比如 #e8e8ea）。对比度降到 13:1 左右，看着反而清楚。

## 变量要分层

我见过直接写 `--bg: #000; --text: #fff` 的写法，改起来会疯。好一点的做法是分两层：

```css
:root {
  --gray-0: #ffffff;
  --gray-900: #0f1115;
  --accent: #3b82f6;
}
:root[data-theme="dark"] {
  --gray-0: #0f1115;
  --gray-900: #e8e8ea;
  --accent: #60a5fa;
}
.card {
  background: var(--gray-0);
  color: var(--gray-900);
}
```

关键点：**变量只在根上定义两套值，组件只写一次规则**。组件里不要出现 `[data-theme="dark"] .card` 这种写法，否则每加一个组件就要改两处，一定会有漏的。

## 三个容易忘的地方

**阴影。** 浅色模式下阴影用黑色加透明度很自然；暗色模式下黑底加黑阴影等于没有。暗色模式的"阴影"一般靠提高元素亮度或者调边框来实现。

**图片。** 纯白的截图放在暗色背景上很刺眼，可以给图片加一点点灰度的过滤，或者降低亮度。但要注意人的照片不要随便滤镜，会显得很奇怪。

**浏览器原生控件。** 滚动条、输入框、下拉框这些是浏览器画的，得显式声明 `color-scheme: dark`，否则会出现白色滚动条配深色页面。

## 最后

写完记得测一下对比度，很多在线工具可以直接查。凭眼睛判断很容易偏——你觉得"看得清"，是因为你刚看完一个亮页面。
