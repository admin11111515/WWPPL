暗色主题看着简单，背景改黑字改白不就完了。真做起来一堆细节，根子都是一个：颜色不是孤立的。

浅色下纯黑字配纯白底，对比度大概 21:1，舒服。反过来暗色下纯白字配纯黑底，对比度也是 21:1，但字边会"发光"，看久了眼累。因为纯黑纯白都是极端值，明暗一切换人眼适应不了。所以暗色背景我用接近黑的深灰，比如 #0f1115，文字用带点灰的近白 #e8e8ea，对比度降到 13:1 左右，反而清楚。

变量我分两层，别直接写 `--bg: #000; --text: #fff`，改起来会疯：

```css
:root {
  --gray-0: #ffffff;
  --gray-900: #0f1115;
  --accent: #3b82f6;
}
:root[data-theme="dark"] {
  --gray-0: #0f1115;
  --gray-900: #e8e8ea;
  --accent: #60a5fa;
}
.card {
  background: var(--gray-0);
  color: var(--gray-900);
}
```

关键就一句：变量只在根上定义两套值，组件只写一次规则。组件里别出现 `[data-theme="dark"] .card` 这种，否则每加一个组件改两处，肯定有漏的。

我同事阿琳有回看我暗色页面说："你这字怎么在发光。" 就是对比度没压。顺手记几个容易漏的点：阴影，浅色下黑加透明很自然，暗色下黑底加黑阴影等于没有，得靠提亮元素或调边框；图片，纯白截图放暗色底上刺眼，给图加一点灰度或降亮度，但人的照片别乱加滤镜，会怪；浏览器原生控件，滚动条、输入框、下拉框是浏览器画的，得显式声明 `color-scheme: dark`，不然白滚动条配深页面。

写完我习惯用工具测下对比度，不靠眼睛。你觉得"看得清"，往往是因为刚看完一个亮页面，眼睛还没缓过来。
